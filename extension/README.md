# Linager Chrome Extension (Manifest V3)

Save any webpage or YouTube video link with title directly into your Linager bookmark hub in **1 click** — without opening the website!

---

## 🚀 How to Install in Google Chrome (or Brave / Edge / Opera)

1. Open your browser and go to:
   ```
   chrome://extensions
   ```
2. Enable **Developer mode** (toggle switch in top-right corner).
3. Click **Load unpacked** (top-left button).
4. Select this folder:
   ```
   E:\Codes\Testing\Linager\extension
   ```
5. Pin **Linager** to your browser toolbar for instant 1-click access! 📌

---

## 🔑 One-Time Connection (30 Seconds)

1. Open your Linager website: [https://linager.pavneet1804.workers.dev](https://linager.pavneet1804.workers.dev) and sign in.
2. In the top-right header, click the **🧩 Extension Key** button. Your secure token will be copied to your clipboard.
3. Click the Linager extension icon in your Chrome toolbar.
4. Paste the token into the **Extension API Token** field and click **Save & Connect**.
5. You're connected! You never need to enter your token again.

## ⚡ Features & Usage

### 1. 1-Click Popup Save
- Click the extension icon on any page.
- Current tab's **Title** and **URL** are auto-filled.
- (Optional) Add tags or check **📌 Pin to top**.
- Click **Save to Linager** (or hit Enter). The link is saved and the popup closes automatically in 1 second!

### 2. Right-Click Context Menu (Instant Save)
- Right-click anywhere on a webpage and click **"Save page to Linager"**.
- Right-click on any hyperlink and click **"Save link to Linager"**.
- A desktop notification will confirm the link is saved — without opening any popups!

### 3. Keyboard Shortcuts
- **`Alt + L`**: Open Linager Save Popup.
- **`Alt + Shift + S`**: Quick Save current tab instantly in the background.
